# School Administrative and Data Management Web Application

## Overview

A web-based school administration system developed as a university group project to improve the management of student academic records and attendance. The application provides a centralized platform for administrators, teachers, and students, with functionality tailored to the Form 6 Biology class.

## Features

- **User Management:** Register and manage administrator, teacher, and student accounts.
- **Grade Management:** Allow teachers to enter and update student assessment marks.
- **Attendance Management:** Enable teachers to record daily student attendance.
- **Student Portal:** Allow students to view their individual grades and attendance records.
- **Role-Based Access:** Provide different functionality according to user roles.

## Technologies Used

- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Frontend:** Thymeleaf, HTML, CSS, JavaScript
- **Data Access:** Spring Data JPA
- **Testing:** JUnit 5

## System Architecture

The application follows a three-tier architecture:

1. **Presentation Layer:** Provides the user interface through Thymeleaf templates and web pages.
2. **Business Logic Layer:** Handles application logic and processing through Spring services.
3. **Data Access Layer:** Manages database operations and persistence using Spring Data JPA repositories.
